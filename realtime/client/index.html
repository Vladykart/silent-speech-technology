TECHNICAL BASIS

Real artifacts,
research bounded.

Released architecture
8-channel raw sEMG → three residual CNN blocks → 6-layer 768-wide relative-position Transformer → 80 mel features + 48 trained phoneme emissions.
Released weights
54,187,136 trainable parameters from Zenodo 6747411, SHA-256 verified and loaded directly. CC BY 4.0; David Gaddy attribution.
Recorded data
Silent Speech EMG v1.0, one speaker, Zenodo 4064409 / concept DOI 4064408, CC BY 4.0. Samples are fetched locally and never committed.
Code / papers
dgaddy/silent_speech @ a89357c, MIT; Gaddy & Klein, EMNLP 2020 / ACL 2021. Source results do not become this project's results.
Decoder adaptation
Legacy DeepSpeech 0.7 is not available for Python 3.12. We decode the released model's real phoneme head with CMUdict and a bounded phoneme-edit grammar; no synthetic replacement model.
Real hardware prerequisite
Reviewed electrodes/device, electrical safety, placement, calibration and governed human-subject protocol. None is present; this page only replays existing records.
