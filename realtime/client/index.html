    TECHNICAL BASIS & LIMITSInspect architecture, adaptation, source code and hardware boundary+
    Released architecture
    Eight-channel raw sEMG → three residual CNN blocks → six-layer, 768-wide relative-position Transformer → 80 mel features + 48 trained phoneme emissions.
    Decoder adaptation
    Legacy DeepSpeech 0.7 is unavailable on Python 3.12. This build decodes the released model's real trained phoneme head with CMUdict and a bounded phoneme-edit grammar; no synthetic replacement model.
    Code reference
    dgaddy/silent_speech at commit a89357c2086609b432919b9d14ffc0be5d8983d5, MIT; Gaddy & Klein, EMNLP 2020 and ACL-IJCNLP 2021. External source results do not become project results.
    Hardware boundary
    A reviewed electrode/device driver, electrical safety, placement, calibration and governed human-subject protocol would be required. None is present. There is no hardware-present claim.
