What is real / 07

Open vocabulary remains narrow

Missing here

Hardware, participant, command accuracy, transfer, complete latency, comfort, power, security, Arabic/Gulf behavior and user value.

MetricTop-1 command accuracy is not WER. Inference time excludes signal window, endpointing, confirmation and output.

Privacy by design / 08

A lock. A data flow. A governance veto.

Before collection

  • voluntary, purpose-limited consent
  • non-biometric alternative
  • ethics/electrical/labor/jurisdiction review
  • separate calibration consent

System targets

  • explicit lock + contact required
  • raw retention/egress off
  • least privilege + deletion
  • confirm before state change

Prohibited

  • emotion/stress/engagement inference
  • productivity scoring
  • covert/bystander sensing
  • unrelated model training

Sources/boundary: UAE official PDPL page; EU Regulation 2024/1689 Article 5(1)(f); NIST Privacy Framework. No compliance certification; UAE Executive Regulations/counsel remain TBD. C18–C21, C28; R18–R20, R32–R33.

Pre-committed decision / 13

Go. Change. Or stop on purpose.

GATE 0 / PROBLEM

Whole task

Voice/touch/shortcut baseline; voluntary user preference.

Stop if existing input wins or power risk remains.

GATE 1 / BENCH

Signal + harm

False accepts/rejects, top-1, complete p50/p95 latency, comfort.

Change montage/grammar if error cannot be contained.

GATE 2 / TRANSFER

Real re-use

Remove/reapply, days, motion/fatigue, adaptation time.

Stop if personalisation defeats workflow value.

GATE 3 / LANGUAGE

Bilingual scope

Native-user approved English/Arabic/dialect command grammar.

Re-scope if gap/corpus cost exceeds plan.

GATE 4 / FIELD

Use + safety

Task success, fallback, use, wear, skin, privacy/security tests.

Hard stop if no net value or controls fail.
