What informed this staged path

The upstream research code loads multi-channel facial EMG, applies signal preprocessing/features, uses convolutional blocks plus a Transformer sequence encoder, and decodes character outputs with CTC beam search and a language model. This demo uses those ideas only as explanatory labels.

Upstream historical result: its README reports approximately 36% open-vocabulary WER for its latest research model/evaluation. That is not reproduced here, not this project’s performance, and not a product claim.

Prerequisites absent here

  • Consented EMG capture hardware, placement protocol, and study data
  • Paired data/alignment assets, trained weights, and language model
  • Python/PyTorch/CUDA, CTC decoder, evaluation, and calibration toolchain
  • Participant/session testing, complete latency, safety, and governance evidence
